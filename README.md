# DSA-lecture-sample
This repository contains sample code of DSA at UIT

## Auto Compile C++ Files

Run the Python script to compile a single C++ file, run it, and clean up the executable:

**Interactive mode (select from list):**
```bash
python auto_compile.py
```

**Direct file argument:**
```bash
python auto_compile.py week-1/brute-force.cpp
python auto_compile.py brute-force.cpp
python auto_compile.py brute-force
```

Requirements:
- Python 3.x
- g++ compiler (MinGW on Windows, build-essential on Linux)
